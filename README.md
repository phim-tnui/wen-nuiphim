## Commands
- `npm run dev` — Start the full-stack Express + Vite development server on `http://0.0.0.0:3000`
- `npm run build` — Build the React SPA into `dist/`
- `npm run start` — Start the production server (`node server.ts`)
- `npm run lint` — Run TypeScript type checking (`tsc --noEmit`)
